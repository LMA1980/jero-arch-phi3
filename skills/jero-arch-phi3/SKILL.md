# `jero-arch-phi3` Fused QKV/Gate-Up Slicing, Zero-Allocation Decode & Parallel `M = 1` / Batched Prefill GEMM

- Implement `jero_core::ArchRecipe` handling fused `attn_qkv` (`Q || K || V`) and fused `ffn_up` (`gate || up`) tensor slicing without intermediate heap copies, plus `LongRoPE` short/long per-dimension frequency scaling factors.
- Execute single-token `Phi3Recipe::decode_step` (`decode_step_with_repack`) with zero steady-state heap allocations by sizing an external `jero_core::ScratchWorkspace` via `Phi3Recipe::required_decode_scratch_bytes(max_seq_len)`, leasing all `128-byte`-aligned decode activations, 1D norm weights, `LongRoPE` tables, and `GQA` scores via `ScratchWorkspace::scope()` (`gqa_attention_with_scratch_f32`), and resolving per-layer tensor keys through stack-allocated `const fn` `Phi3LayerDescriptor::for_layer(layer)` entries (`0` per-layer `format!` allocations).
- Partition output rows of pre-split `(Wq, Wk, Wv, Wo, Wgate, Wup, Wdown)` (`Phi3SplitMatrix::{gemv_rows, gemv_quantized_rows, gemv_quantized_parallel, gemv_parallel}`) and the tied/untied `32k`–`200k` LM head (`gemv_q4_k_q8_k` / `gemv_q5_k_q8_k` / `gemv_q6_k_q8_k` / `gemv_q4_0_q8_0_4x` / `gemv_q5_0_q8_0_4x` / `gemv_q8_0_q8_0_4x` / `vec_dot_{f16,bf16}` / chunked `F32`) across active `WorkerPool` threads via `REPACK_TILE_ROWS` / `4`-row-aligned recursive `rayon::join` slices, producing bit-identical `decode_step` logits across `1`, `4`, and `8` worker partitions without `7/8` `TILE_M = 8` zero-padded waste.
- Execute `Phi3Recipe::prefill_step` (`prefill_step_with_repack`) across `[M, hidden_dim]` prompt chunks per layer via `QuantizedActQ8::quantize_into` shared once across `(Wq, Wk, Wv)` and once across `(Wgate, Wup)`, dispatching tile-row-sliced `gemm_repacked_rows` on `A100` `XSMTVDotII` (`smt.vmadot`) / `RVV`, batched `LongRoPE` (`apply_rope_with_cos_sin`), and KV-head-partitioned `gqa_causal_attention_prefill_f32` with `ExecutionContext` `start_position` chunking, while projecting only final token `M - 1` through the LM head when `ctx.compute_logits()` is enabled.
- Use `Phi3ModelRepack` (`Phi3RepackCache`) / `Phi3LayerRepack` to pre-split fused `attn_qkv.weight` into independent `(Wq, Wk, Wv)` and `ffn_up.weight` into `(Wgate, Wup)` `128-byte`-aligned `jero_kernels_rvv::RepackedWeight` matrices and cache decoded `f32` `RMSNorm` vectors once at model load (with ABA-safe bounded layer caching in `prefill_step` / `decode_step` under `with-kernels`), preventing `8x16` tile straddling across GQA and non-multiple-of-8 slice boundaries.
- Enforce fail-closed `K3Error::CapabilityMismatch` vocabulary bounds across GGUF metadata, `token_embd.weight` / `output.weight` shapes, special token IDs, and logit buffers, and extract `PhiStopMetadata` (`Phi3End` `<|end|>` vs `Phi4ImSep` `<|im_sep|>` / `<|im_end|>`) for `jero_core::StopCriteria`.
- Preserve portable scalar parity under `--no-default-features` and delegate to `jero-kernels-rvv` when `with-kernels` is enabled.
